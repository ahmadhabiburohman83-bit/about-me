# 08 — Problem Solving Strength and Automation [EN]

Part of: [[03_Pola_Diri_Utama_EN|03 Core Pattern]] • Indonesian: [[08_Kekuatan_Problem_Solving_Dan_Otomatisasi|08 ID]]

## Core
This is my strength, don't throw it away.

- Fast thinking, solution-oriented.
- Not stopping at anger: find the cause, try another way, repeat until muscle memory.
- Same with others: if they truly try but keep failing, I still find another way instead of labeling them "incapable". Maybe the method is wrong.

## How to use it without burnout
1. Limit iterations: e.g. 3 tries → mandatory break.
2. Write down methods tried, not just in my head.
3. Automate only after a break, not at peak exhaustion.
