# 05 — Expectation Frustration Exhaustion Cycle [EN]

Part of: [[03_Pola_Diri_Utama_EN|03 Core Pattern]] • Indonesian: [[05_Siklus_Ekspektasi_Frustrasi_Lelah|05 ID]]

## Core
My problem isn't lack of motivation. I run out of capacity because I keep forcing.

## The cycle
**high expectations → result doesn't match → frustration → trying harder → more exhausted → ability drops → even more frustrated → keep forcing myself.**

My healthy problem-solving version:
**problem → frustration → find cause → try another way → repeat → automate.**

What breaks it is repeating "try again" endlessly without a break when already tired.

## Signs I'm in the broken cycle
- Looping thoughts: "It should be done / I should be able to do this / why isn't it working?"
- Body tired but will to succeed still high.
- Results drifting further away.

## Emergency brake
Pausing ≠ giving up. Ask: "What is blocking me in my CURRENT condition?" — not "why am I a failure?"
